# Ethical Hacking Practicals

This repository contains hands-on cybersecurity and ethical hacking practical experiments performed using Kali Linux and various security tools.

## Topics Covered
- Passive & Active Reconnaissance
- Whois, Nslookup, Google Dorking
- Network Scanning using Nmap
- Enumeration using Enum4Linux
- Password Cracking using Hydra
- Hashcat Attacks
- John the Ripper
- Privilege Escalation
- XSS using DVWA
- SQL Injection
- Packet Analysis using Wireshark
- Burp Suite Request Interception

## Tools Used
- Kali Linux
- Nmap
- Wireshark
- Burp Suite
- Hydra
- Hashcat
- John the Ripper
- DVWA

## Disclaimer
This project is created strictly for educational and ethical learning purposes only.
